I built a web-scraping pipeline for a medical RAG project using uv, requests, and BeautifulSoup. It extracts clinic profile sections, FAQs, reviews, and written testimonials into structured JSON while keeping the source URL for attribution.

What is HTML Parsing?
Website ka raw HTML dekhne mein code jaisa hota hai. HTML parsing us code ko samajhne layak parts—jaise heading, paragraph aur review—mein todti hai, taa-ke hum sahi text nikaal saken aur menu ya popup ko chhor saken.

HTML parse karna is tarah samjho:
1. Website ka HTML ek raw file hota hai—usmein page ka text, menu, buttons aur doosra code mila hota hai.
2. BeautifulSoup is HTML ko samajh kar elements mein organize karta hai, jaise headings (h2), paragraphs (p) aur review cards.
3. Phir hum specific elements dhoondh sakte hain—jaise FAQ ka sawal ya review ka rating—and menu aur popups ko hata sakte hain.
4. Is tarah humein useful content saaf, structured form mein milta hai jo RAG ke liye process karna aasaan hota hai.
